# Portfolio illustrations

Original, editable SVG artwork authored for furtak.dev and the GitHub profile, September 2026. The illustrations explain map composition and shared UI state; they are conceptual artwork, not screenshots or proof of application behavior. No image-generation API was used.

- `engineering-layers.svg`: shared visual motif for the homepage.
- `map-composition.svg`: map/view/source layers for the library project.
- `adapter-architecture.svg`: feature state independent of table renderers.

Artwork uses no scripts, external fonts, external images or network dependencies. The site's self-hosted Manrope font and its SIL Open Font License are under `public/fonts/`.
