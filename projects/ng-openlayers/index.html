ng-openlayers: Angular components for OpenLayers

Declarative Angular components for OpenLayers maps, built to keep map structure in templates while preserving access to the underlying OpenLayers APIs.

The library is published as the ng-openlayers npm package, with source code on GitHub and a live demo at ng-openlayers.furtak.dev.

Install in an Angular application

ng-openlayers 22 supports Angular 22, OpenLayers 10.10+ and Proj4 2.22+. Install the library and its peer dependencies: 

npm install ng-openlayers@22 ol@10 proj4@2

For Angular 21, use ng-openlayers 21.2.x. Check the published package for current releases and the Angular 22 migration guide before upgrading an existing app.

Follow the Angular OpenStreetMap tutorial for the stylesheet, a complete standalone component and common setup problems.

Purpose

Angular applications often need map-heavy workflows: operational dashboards, asset views, field forms, analytical tools and geospatial data exploration. OpenLayers is a strong engine for those interfaces, but raw setup code can become an imperative island inside an Angular app.

ng-openlayers turns the map hierarchy into Angular component composition: map, view, layers, sources, features, styles, controls, interactions and overlays can be declared in templates and configured with typed inputs.

Capabilities

  • Template-driven map, view, layer, source and style composition.
  • Angular bindings for OpenLayers controls, interactions and overlays.
  • Event outputs for map, view, interaction and feature workflows.
  • Examples for markers, GeoJSON, WMS, ArcGIS sources, drawing, selection and measurement flows.

My maintainer work

I maintain the Angular wrapper, building on the existing open-source work credited in the repository. My focus is component and event lifecycle ownership, projection changes, API compatibility and release validation. The demo has 27 interactive examples; an independent Angular consumer installs the built npm package to check the distribution boundary.

The current release and supported Angular versions are listed on npm as ng-openlayers and the live demo is deployed on ng-openlayers.furtak.dev through GitHub Pages.

Validation and maintenance

See the validation scope and reproducible commands for lifecycle and projection regressions, test coverage boundaries and browser checks. The source and demo can include fixes not yet released on npm; package versions and releases remain authoritative for installed consumers.
