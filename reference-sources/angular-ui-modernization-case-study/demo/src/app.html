State belongs to the feature

A small signal-based store owns the query, selected IDs and asynchronous loading. Pure functions define filtering and sorting independently of Angular or PrimeNG.

Adapters only render

Both tables consume the same typed rows and emit neutral intents. PrimeNG is confined to its adapter. Replacing it does not change the form or reset the queue.

Limits are explicit

Six synthetic records, an in-memory API and browser-local drafts. No authentication, backend persistence, virtual scrolling or claim of production-scale performance.
